# ovi_os/

## Purpose

Documenta OVI OS: el sistema operativo de gestión de limpieza industrial desarrollado por OVI. Este módulo es uno de los diferenciadores estratégicos clave de la plataforma y representa la convergencia entre tecnología y operación de limpieza.

## Expected Files

- `ovi_os_overview.md` — Descripción general de OVI OS: qué es, para qué sirve, a quién va dirigido y qué lo diferencia.
- `features.md` — Listado detallado de funcionalidades: dashboards, gestión de protocolos, reportes, alertas, integración con IA.
- `user_roles.md` — Roles de usuario dentro de OVI OS (administrador, supervisor, operativo, cliente) y sus permisos.
- `integrations.md` — Integraciones con sistemas externos: ERP, CRM, sensores IoT, plataformas de certificación.
- `roadmap_os.md` — Hoja de ruta de desarrollo de OVI OS con versiones y fechas estimadas.
- `demo_flows.md` — Flujos de demostración para el sitio web y presentaciones comerciales.

## How the Information Will Be Consumed

- La sección "OVI OS" del sitio web consume `ovi_os_overview.md` y `features.md` para generar la página de producto.
- El asistente de IA usa `features.md` y `user_roles.md` para responder preguntas sobre el sistema.
- Los dashboards interactivos del sitio se diseñan a partir de los flujos en `demo_flows.md`.
- El módulo de ventas referencia `roadmap_os.md` para presentar el plan de evolución del producto.

## Dependencies

- `ai/` — El componente de IA es parte integral de OVI OS.
- `protocols/` — Los protocolos se gestionan dentro de OVI OS.
- `architecture/` — Arquitectura técnica del sistema.
