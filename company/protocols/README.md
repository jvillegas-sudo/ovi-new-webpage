# protocols/

## Purpose

Repositorio de los protocolos técnicos de limpieza desarrollados y validados por OVI. Este directorio sustenta el posicionamiento "Ingeniería en Limpieza" y es la base del conocimiento técnico de la plataforma.

## Expected Files

- `protocols_index.md` — Índice maestro de todos los protocolos disponibles con categorías y versiones.
- `protocol_[nombre].md` — Protocolo individual: objetivo, alcance, insumos requeridos, pasos del procedimiento, parámetros de control, frecuencia, responsables, evidencia de validación.
- `certification_standards.md` — Normas y certificaciones que respaldan los protocolos (ISO, HACCP, NOM, NSF, etc.).
- `protocol_templates.md` — Plantillas estandarizadas para la documentación de nuevos protocolos.

## How the Information Will Be Consumed

- El asistente de IA de OVI OS utiliza los protocolos como base de conocimiento técnico para responder preguntas operativas.
- Las páginas de servicios referencian los protocolos para validar la propuesta de valor.
- Los dashboards operativos del cliente pueden mostrar el cumplimiento de protocolos en tiempo real.
- El módulo de consultoría utiliza estos protocolos como entregables técnicos.

## Dependencies

- `industries/` — Normativas sectoriales que definen los requisitos de cada protocolo.
- `products/` — Productos necesarios para ejecutar cada protocolo.
- `knowledge/` — Integración con la base de conocimiento general.
