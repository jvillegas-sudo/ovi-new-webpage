# OVI DESIGN LANGUAGE — REGLAS VISUALES

> **FOUNDATION ORDER 003 · Entregable 7 de 7**  
> Estado: Aprobado — Pendiente de implementación  
> Versión: 1.0

---

## REGLA MAESTRA

> **Si un elemento visual no representa limpieza, ingeniería, precisión o sostenibilidad → No pertenece a OVI.**

Toda decisión visual futura pasa por este filtro antes de cualquier otra consideración.

---

## REGLA DE CONSISTENCIA DE ESCENA

Toda nueva escena debe responder afirmativamente a esta pregunta:

> **¿Este elemento pertenece naturalmente al universo OVI de Ingeniería en Limpieza?**

Si la respuesta es NO → debe rediseñarse antes de avanzar.

---

## REGLAS POR ELEMENTO

### AGUA

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Comportarse como herramienta de ingeniería. |
| ✅ Siempre | Representar transformación, precisión y limpieza. |
| ✅ Siempre | Usar en formas controladas: micro gotas, ondas, películas, flujo. |
| ❌ Nunca  | Representar como océano, mar, lago o cuerpo de agua no controlado. |
| ❌ Nunca  | Asociar con naturaleza o paisaje. |

### ESPUMA

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Verse elegante, controlada y premium. |
| ✅ Siempre | Usar para revelar, generar transiciones o explicar procesos. |
| ❌ Nunca  | Espuma caricaturesca, de caricatura o de dibujo animado. |
| ❌ Nunca  | Usar como decoración sin función narrativa. |

### VAPOR

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Representar desinfección, energía y procesos térmicos. |
| ✅ Siempre | Usar con iluminación volumétrica. |
| ❌ Nunca  | Verse como humo (connotación de contaminación o fuego). |
| ❌ Nunca  | Usar sin fuente de calor o proceso narrativo justificado. |

### LUZ

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | La luz escanea, guía, revela o diagnostica. |
| ✅ Siempre | La luz tiene un origen y una dirección intencional. |
| ❌ Nunca  | Haces de luz aleatorios sin propósito narrativo. |
| ❌ Nunca  | Flares decorativos sin fuente justificada. |

### MATERIALES

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Usar materiales de la lista oficial (vidrio, cristal, acero, fibra de carbono, cerámica, superficies industriales). |
| ❌ Nunca  | Materiales rocosos, terrenos o elementos naturales como protagonistas. |
| ❌ Nunca  | Materiales que evoquen suciedad, deterioro o descuido. |

### CÁMARA

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Movimiento cinematográfico y elegante. |
| ✅ Siempre | Easing suave. Sin aceleración o desaceleración bruscas. |
| ❌ Nunca  | Movimientos arcade, bruscos o de videojuego. |
| ❌ Nunca  | Shake sin propósito narrativo. |

### PARTÍCULAS

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Las partículas representan moléculas, micro gotas, burbujas o nanopartículas. |
| ✅ Siempre | El movimiento es vectorizado y con propósito físico. |
| ❌ Nunca  | Partículas de estrella, espacio, fuego o DNA. |
| ❌ Nunca  | Partículas en movimiento caótico sin narrativa. |

### TRANSICIONES

| Regla | Descripción |
|-------|-------------|
| ✅ Siempre | Cada transición cuenta una historia del universo OVI. |
| ✅ Siempre | Usar los tipos aprobados (onda, espuma, vapor, escáner, limpieza). |
| ❌ Nunca  | Fades simples sin contexto narrativo. |
| ❌ Nunca  | Cortes duros entre escenas 3D. |

## CHECKLIST DE APROBACIÓN VISUAL

Antes de aprobar cualquier escena, asset o componente visual, verificar:

- [ ] ¿El elemento pertenece al universo de limpieza e ingeniería?
- [ ] ¿Los materiales son de la lista oficial?
- [ ] ¿La paleta de colores respeta los tokens OVI?
- [ ] ¿Las partículas tienen significado físico-narrativo?
- [ ] ¿La iluminación tiene propósito (escanear, guiar, revelar, diagnosticar)?
- [ ] ¿El movimiento de cámara es cinematográfico y elegante?
- [ ] ¿La transición cuenta una historia del universo OVI?
- [ ] ¿El elemento elimina o reemplaza activamente elementos prohibidos?

Si algún punto es NO → el elemento no está listo para implementación.

---

## PROCESO DE APROBACIÓN

1. El diseñador propone el elemento con referencia a esta guía.
2. Se verifica con el checklist anterior.
3. Se aprueba por el responsable de marca OVI.
4. Se implementa en el próximo ciclo de desarrollo.

**Sin aprobación formal → sin implementación.**
